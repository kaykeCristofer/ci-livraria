# Livraria TDD — site (React + Vite)

```bash
npm install
npm run dev      # servidor local em http://localhost:5173
npm run build    # gera dist/ (o que vai para o GitHub Pages)
npm run preview  # serve o dist/ localmente
```

- `base: './'` no `vite.config.js` faz o build funcionar em `usuario.github.io/<repo>/` sem configurar o nome do repositório.
